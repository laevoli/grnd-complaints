─── ШАГ 1: Установите необходимые программы ─────────────

1) Node.js (версия 18 или выше):
   Скачать: https://nodejs.org/
   Выбрать «LTS» версию → установить.


2) PostgreSQL (база данных):
   Скачать: https://www.postgresql.org/download/
   При установке запомните пароль для пользователя postgres.
   Порт оставьте по умолчанию: 8530(5433)

3) Git (для скачивания проекта):
   Скачать: https://git-scm.com/downloads


─── ШАГ 2: Скопируйте проект ───────────────────────────

Если у вас архив проекта — распакуйте его в любую папку.
Если клонируете с GitHub:
   git clone https://github.com/ВАШ_РЕПОЗИТОРИЙ admintrack
   cd admintrack


─── ШАГ 3: Создайте базу данных ────────────────────────

СЛЕДУЮЩИЙ ШАГ




Откройте «SQL Shell (psql)» (устанавливается вместе с PostgreSQL)
или pgAdmin, и выполните:

   CREATE DATABASE app_db;

Либо в командной строке:
   psql -U postgres -c "CREATE DATABASE app_db;" qpwoeiruty


─── ШАГ 4: Настройте .env файл ─────────────────────────

В папке проекта найдите файл .env
Откройте его блокнотом и убедитесь, что там написано:

   DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@127.0.0.1:5432/app_db

Замените ВАШ_ПАРОЛЬ на пароль от PostgreSQL который задали при установке.


─── ШАГ 5: Установите зависимости ─────────────────────

Откройте командную строку (CMD / PowerShell / Terminal)
в папке проекта и выполните:

   npm install


─── ШАГ 6: Создайте таблицы в базе ────────────────────

   npx drizzle-kit push


─── ШАГ 7: Запустите сайт ──────────────────────────────

Режим разработки (с авто-перезагрузкой):
   npm run dev

Откройте браузер: http://localhost:3000

Для продакшн-режима:
   npm run build
   npm start


─── ШАГ 8: Всё готово! ─────────────────────────────────

Перейдите на http://localhost:3000
Вкладки:
  • Статистика    — рейтинг администраторов
  • Администраторы — управление составом
  • Загрузить ЖБ  — вставить форму жалобы
  • Список ЖБ     — все загруженные жалобы

─── Добавление администратора ──────────────────────────

1. Вкладка «Администраторы» → кнопка «Добавить»
2. Заполните:
   - Никнейм (точно как в игре, например: Derek_Gold)
   - Уровень от 1 до 5
   - URL фото (ссылка на фото, необязательно)
   - Дату начала/конца отпуска (необязательно)
   - Переключатели: «В отпуске» и «Инструктаж пройден»
3. Нажмите «Сохранить»


─── Быстрое переключение отпуска / инструктажа ─────────

На карточке каждого администратора есть кнопки:
  🏖️ — поставить/снять отпуск
  📋 — поставить/снять отметку об инструктаже
  ✏️ — редактировать администрёёатора
  🗑️ — удалить (потребует подтверждение)


─── Загрузка жалоб (ЖБ) ───────────────────────────────

Вкладка «Загрузить ЖБ»:

1. Нажмите «Вставить шаблон» или просто вставьте форму:

язык:      ru
сервер:   19
номер жб:  4113357
от кого: Maxim_Vpotoke
на кого:  Hanbenri_Kamssynt
кто обработал:   Derek_Gold
время подачи:  08.11.2026, 22:07:51
время закрытия:   08.11.2026, 22:09:55

2. Нажмите «Загрузить»

НЕСКОЛЬКО ЖБ СРАЗУ:
Просто разделите блоки пустой строкой:

язык:      ru
сервер:   19
номер жб:  4113357
...

язык:      ru
сервер:   19
номер жб:  4113358
...


─── Просмотр статистики ────────────────────────────────

Вкладка «Статистика» — рейтинг всех администраторов:
  - Количество закрытых ЖБ за: день / неделю / месяц / всего
  - Уровень администратора (1-5 звёзд)
  - Статус: отпуск / инструктаж
  - Топ-3 выделены медалями 🥇🥈🥉

════════════ ВАРИАНТ A: Vercel (Бесплатно, Просто) ════════════

1. Загрузите проект на GitHub:
   - Создайте аккаунт на https://github.com
   - Создайте новый репозиторий
   - Загрузите проект:
     git init
     git add .
     git commit -m "initial commit"
     git remote add origin https://github.com/ВАШ_ЛОГИН/admintrack.git
     git push -u origin main

2. Создайте PostgreSQL базу в интернете (бесплатно):
   - Зайдите на https://neon.tech или https://supabase.com
   - Зарегистрируйтесь и создайте новый проект
   - Скопируйте строку подключения (DATABASE_URL)
   - Она выглядит примерно так:
     postgresql://user:password@host/dbname?sslmode=require

3. Деплой на Vercel:
   - Зайдите на https://vercel.com
   - «New Project» → выберите ваш GitHub репозиторий
   - В разделе «Environment Variables» добавьте:
     DATABASE_URL = postgresql://ваша_строка_подключения
   - Нажмите «Deploy»

4. После деплоя примените схему БД:
   В папке проекта на локальном ПК:
   DATABASE_URL=postgresql://ваша_строка → npx drizzle-kit push

   Или через Vercel CLI:
   npx vercel env pull
   npx drizzle-kit push

5. Ваш сайт доступен по адресу: https://ваш-проект.vercel.app


════════════ ВАРИАНТ B: Railway (Простой хостинг+БД) ══════════

1. Зайдите на https://railway.app
2. «New Project» → «Deploy from GitHub repo»
3. Добавьте PostgreSQL сервис: «+ New» → «Database» → «PostgreSQL»
4. Скопируйте DATABASE_URL из вкладки «Variables» базы
5. Добавьте в переменные вашего приложения DATABASE_URL
6. Railway сам соберёт и запустит проект

════════════ ВАРИАНТ C: VPS / Сервер (Полный контроль) ════════

1. Арендуйте VPS (DigitalOcean, Hetzner, Timeweb, etc.)
   Минимум: 1 vCPU, 1 GB RAM

2. Установите на сервере:
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo bash -
   sudo apt install -y nodejs postgresql nginx

3. Создайте базу:
   sudo -u postgres psql -c "CREATE DATABASE app_db;"
   sudo -u postgres psql -c "CREATE USER admintrack WITH PASSWORD 'password';"
   sudo -u postgres psql -c "GRANT ALL ON DATABASE app_db TO admintrack;"

4. Скопируйте проект на сервер (через git или scp)

5. В папке проекта:
   npm install
   npm run build
   npx drizzle-kit push

6. Запустите с PM2 (менеджер процессов):
   npm install -g pm2
   pm2 start "npm start" --name admintrack
   pm2 save
   pm2 startup

7. Настройте Nginx (обратный прокси):
   sudo nano /etc/nginx/sites-available/admintrack

   Вставьте:
   server {
       listen 80;
       server_name ваш-домен.com;
       location / {
           proxy_pass http://localhost:3000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }

   sudo ln -s /etc/nginx/sites-available/admintrack /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl restart nginx

8. HTTPS (бесплатно через Let's Encrypt):
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d ваш-домен.com

Q: Почему статистика «за день» показывает 0?
A: Статистика считается по времени закрытия (closedAt).
   Убедитесь что дата в форме соответствует сегодняшнему дню.

Q: Как изменить язык/сервер по умолчанию?
A: В форме загрузки ЖБ просто измените значение в поле
   «язык:» или «сервер:». Либо отредактируйте шаблон в
   файле src/components/BulkImportPanel.tsx

Q: Можно ли загрузить несколько ЖБ сразу?
A: Да! Вставьте несколько форм, разделённых пустой строкой.

Q: Фото администратора — откуда взять ссылку?
A: Загрузите фото на https://imgur.com или любой хостинг изображений,
   скопируйте прямую ссылку (ending с .jpg/.png) и вставьте в поле «URL фото».

Q: Как сделать резервную копию базы?
A: pg_dump postgresql://postgres:пароль@localhost/app_db > backup.sql
   Восстановить: psql postgresql://postgres:пароль@localhost/app_db < backup.sql
